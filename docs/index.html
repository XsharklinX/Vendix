01 / EL PRODUCTO

Un sistema ligero.
Sin puntos ciegos.

Vendix reemplaza herramientas dispersas por un flujo operativo coherente. Cada venta actualiza stock, alimenta reportes y construye el historial del cliente.

Puede funcionar como app web, en una red local o como aplicacion de escritorio para Windows.

01Base unificada

Ventas, costos, clientes y equipo comparten el mismo contexto.

02Operacion diaria

Disenado para vender rapido y revisar lo importante sin friccion.

03Local-first

SQLite y Electron permiten una experiencia simple en escritorio.

Nota tecnica

SQLite es una opcion practica para escritorio y red local. Para produccion cloud con concurrencia real, conviene planificar almacenamiento persistente o migracion a PostgreSQL.

06 / PREGUNTAS FRECUENTES

Antes de empezar.

Respuestas directas para entender el alcance actual y tomar una decision informada.

Vendix funciona sin internet?+

La modalidad de escritorio puede operar localmente. El POS tambien incluye una cola de ventas offline para sincronizar al recuperar conexion. Algunas integraciones, como email o IA, requieren internet.

Puedo usarlo desde un movil o tablet?+

Puede abrirse desde el navegador si el backend esta disponible en red local o cloud. La optimizacion PWA y la experiencia movil dedicada forman parte de las mejoras planificadas.

Incluye facturacion fiscal para Republica Dominicana?+

Incluye datos fiscales, NCF, numeracion propia y documentos imprimibles. Antes de usarlo como sistema fiscal definitivo, valida el flujo requerido por tu negocio y la normativa aplicable.

Sirve para varios negocios?+

Si. Un propietario puede gestionar multiples negocios desde la misma cuenta y mantener inventario, clientes y configuracion separados.

Donde se guardan los datos?+

En la modalidad local, Vendix usa SQLite. Para cloud se recomienda almacenamiento persistente o una migracion planificada a PostgreSQL.

Esta listo para produccion?+

Las bases operativas estan implementadas y el proyecto sigue en desarrollo activo. Revisa el roadmap, configura secretos seguros, prueba backups y valida tu escenario antes de usar datos criticos.
