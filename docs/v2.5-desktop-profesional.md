# v2.5 - Desktop profesional

## Objetivo

Hacer que la instalacion, actualizacion y mantenimiento local de Vendix sean mas confiables para uso diario en Windows.

## Implementado

### Auto-update visible

- Electron mantiene un estado interno de actualizacion.
- Configuracion > Sistema muestra:
  - version instalada
  - canal activo
  - estado de busqueda/descarga
  - aviso visible cuando hay una version descargada
  - boton para reiniciar e instalar

### Canal estable/beta

- Se agrego selector de canal desde Configuracion.
- El canal estable usa `latest`.
- El canal beta usa `beta` y habilita prereleases.
- Scripts nuevos:
  - `npm run release:github:stable`
  - `npm run release:github:beta`
  - `npm run release:github`

### Logs accesibles

- Configuracion > Sistema permite abrir el log local y la carpeta de datos de usuario.
- Se muestra la ruta del log, ultima actualizacion y las ultimas lineas utiles.

### Backup y restauracion mas seguros

- Restaurar backup ahora es un flujo de dos pasos:
  - validar archivo JSON
  - confirmar restauracion
- La validacion muestra origen, fecha de exportacion, conteos por entidad y advertencias.

### Reparador basico de base de datos

- Nuevo chequeo de integridad SQLite con `PRAGMA integrity_check`.
- Reparacion basica con:
  - `PRAGMA optimize`
  - `REINDEX`
  - `VACUUM`
- Si persiste el fallo, la UI indica restaurar un backup validado.

### Instalador mas pulido

- Configuracion de Windows reforzada:
  - icono propio
  - nombre de producto
  - publisher
  - shortcuts de escritorio y menu inicio
  - firma/verificacion preparada por electron-builder

## Pendiente externo

La firma real de codigo requiere un certificado Windows valido. Para publicar firmado se deben configurar variables de entorno compatibles con electron-builder:

- `CSC_LINK`
- `CSC_KEY_PASSWORD`

Sin certificado, el build puede generar instalador, pero Windows seguira mostrando advertencias de confianza.

## Verificacion

- `npm run build:backend`
- `npm run build:frontend`
- `npm run build:electron`

Resultado: correcto. Persisten advertencias no bloqueantes de Vite/PostCSS y aviso de npm.

## Riesgos

- El updater solo funciona en app instalada, no en modo desarrollo.
- El canal beta requiere publicar releases beta con metadata `beta.yml`.
- La reparacion SQLite es basica; no reemplaza una restauracion desde backup si hay corrupcion real.
