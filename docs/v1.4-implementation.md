# Vendix v1.4 - Facturacion profesional

Fecha: 2026-05-28

## Implementado

- Configuracion de facturacion en `Configuraciones`.
- Logo del negocio por URL publica.
- Prefijo y secuencia separada de NCF: `invoicePrefix` + `invoiceSequence`.
- Plantillas de factura: `classic`, `modern`, `thermal`.
- Factura HTML imprimible por venta.
- Envio de factura por email desde el modal de venta exitosa.
- Envio de cotizacion por email desde backend.
- Estado de cuenta del cliente en HTML imprimible.
- Envio de estado de cuenta por email desde cuentas por cobrar.
- Auditoria de envios de factura, cotizacion y estado de cuenta.

## Limitaciones

- El backend envia facturas/estados como archivo `.html` imprimible adjunto, no como PDF binario real.
- Para PDF real del lado servidor se recomienda agregar una dependencia de renderizado como Playwright/Puppeteer o una libreria HTML-to-PDF.
- El boton de email de venta depende de que la venta tenga cliente con email registrado.
- El numero de factura se consume al enviar email desde backend. La impresion local desde frontend puede usar timestamp si no se pide numero al backend.
